# OpenRhiza 요구사항과 출처 추적

[영문 원문](REQUIREMENTS.md) · [한국어 목차](../README.ko.md)

이 목록은 기존 아키텍처나 구현 완료 주장을 승계하지 않고 사용자의 의도를 보존합니다.
사용자가 직접 제시한 요구가 과거 문서보다 우선합니다. 저장소에서 반복된 목표는 보조 근거이며,
개별 AI 제안은 새로운 사용자 요구로 간주하지 않습니다.

아래 요구사항은 새 런타임에서 모두 아직 구현되지 않았습니다. R0는 요구 취합과 아키텍처 기준 수립까지만
완료합니다. 세부 ABI 필드와 시험 허용치는 각 단계에 들어갈 때 버전을 갖춘 통과 계약으로 정의합니다.

Astra 검토를 반영한 [구현 착수·통과 기준](IMPLEMENTATION_GATES.ko.md)은 각 계약을 언제 선정·강제·시험할지
정합니다. 수치 후보는 측정 결과가 아닙니다. 수락시험 전에 환경별 임계값을 확정해야 합니다.
계획 검토 완료는 구현이나 진입 조건 통과를 의미하지 않습니다.

## 근거 구분

설계, 조사 목록, 호스트 모델, 호스트 라이브러리·실험실, 게스트 실행, 에뮬레이트된 장치 실행,
실제 하드웨어, 적대적 시험·장시간 시험을 구분합니다. 각 주장에는 소스·바이너리 해시, 빌드·도구 버전,
설정, 시험 버전, 입력, 측정 결과, 실패·복구 동작을 연결합니다.

매니페스트와 서명은 산출물의 정체성과 허가를 입증하며, 기능의 정확성을 입증하지는 않습니다.
시뮬레이터는 자신의 모델을 검증할 뿐 Rust 드라이버를 자동으로 검증하지 않습니다.
게스트 코드는 실제 운영 경로로 호출해야 합니다. 시험 전용 export나 상태 플래그 변경으로 실제 서비스 동작을 입증할 수 없습니다.

## 요구사항으로 채택하지 않은 제안

- 과거 분석의 B2B 샌드박스 제품·엣지/IoT 전환 제안은 확장 가능성이지만, 사용자의 목표는 독립 범용 OS입니다.
- 인간 개입을 완전히 제거한다는 연구 문구가 명시적 동의, 개인정보 보호, 기본 자율 모드 꺼짐, 결정적 권한 판단을 우선할 수 없습니다.
- LLM·텔레메트리 자동 투표는 검색·진단의 참고 정보이며 안전 증명이 아닙니다.
- 커널 내부 Wasm, 네이티브 실행으로의 "승격", 고정 FAT 슬롯, 전역 객체 번호, 특정 Gemini 모델, 임시 JS·HTML 파서는 과거 구현 선택입니다.
- KDE/GNOME 호환성은 후속 과제입니다. 초기 커널·데스크톱 의존성이 되지 않습니다. 나중의 표준·구성요소 포팅과 Linux 배포판으로의 교체는 다릅니다.
- 브라우저·방화벽·메모리 검사기·Wi-Fi 드라이버·컴파일러라는 이름의 데모가 해당 기능의 구현을 의미하지 않습니다. 무제한 커널 메모리 패치는 허용하지 않습니다.
- 과거 완료율, 프레임 카운터, ARM 증명 이정표를 새 구현에 승계하지 않습니다.

## 추적 정보 유지

새 모듈, 아키텍처 결정, 시험은 이 요구사항 ID를 참조합니다. 세부 사항을 추가하더라도 공개 지원 범위를
조용히 확대하지 않습니다. 미룬 목표는 보존하되 통과 기준을 충족한 플랫폼·기능만 공개합니다.
요구가 충돌하면 구현 코드를 추가하기 전에 [방향 문서](DIRECTION.ko.md)에 명시적으로 결정합니다.
