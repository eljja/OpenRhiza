# OpenRhiza Validation Matrix

This file tracks what has been validated, what is partial, and what is only designed.

Status values:

- `PASS`: recently validated and expected to work.
- `PARTIAL`: implemented or scaffolded, but not fully hardened.
- `DESIGN`: documented target, not active enough to rely on.
- `BLOCKED`: known issue prevents normal use.
